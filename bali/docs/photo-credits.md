# Фотографии

На странице только два источника: съёмка команды и фотографии мест,
где группа живёт. Стоковых и чужих пейзажных кадров нет.

| Файл | Где на странице | Источник |
| --- | --- | --- |
| `hero`, `hero-tall` | Первый экран (десктоп / телефон) | съёмка команды |
| `manifesto` | Манифест | съёмка команды |
| `practice-body` | Практики, утро | съёмка команды |
| `practice-sound` | Практики, вечер | съёмка команды |
| `ilya`, `vita` | Ведущие | съёмка команды |
| `lab-ilya`, `lab-vita` | Илья и Вита вместе | съёмка команды |
| `andrey` | Организатор | архив команды |
| `ubud-fog` | Широкий кадр перед размещением | вилла в Убуде |
| `stay-ubud-*` | Где живём, Убуд | вилла в Убуде |
| `stay-meno-*` | Где живём, Гили Мено | объект на Гили Мено |
| `og-image` | Обложка для мессенджеров | собирается из `hero`, `scripts/og/og-template.html` |

Кадры объектов взяты по решению заказчика, который бронирует эти места.
Письменного разрешения объектов на публикацию пока нет — закрывается одним
письмом, шаблон в `accommodation-request.md`.

## Как заменить или добавить кадр

1. Исходник — в `scripts/bali-originals/`.
2. В `scripts/prepare_bali_photos.py` в `SHOTS`: файл, пропорции, ширина,
   точка кропа и профиль цвета (`team`, `hotel`, `mono`, `pair-warm`, `pair-cool`).
3. `python3 scripts/prepare_bali_photos.py`, затем `python3 scripts/build_bali.py`.
