# Соль. Рис. Тишина. — лендинг

Путешествие-практика по Бали и Гили Мено, 12–22 февраля 2027.
Собран по ТЗ «ПРОЕКТ БАЛИ 2027» от 14 сентября 2026.

## Как устроено

```
bali/
  content.json   ← весь текст, даты, цены, контакты, программа. Правится здесь.
  index.html     ← собирается из content.json, руками не правится
  styles.css     ← дизайн-система
  script.js      ← меню, аккордеоны, форма, аналитика
  docs/          ← внутренние материалы (на сайт не попадают)
scripts/
  build_bali.py  ← сборка
```

Страница статическая: ни одного внешнего скрипта, только шрифты Google.
Весь текст программы лежит в HTML и индексируется.

## Сборка

```bash
python3 scripts/build_bali.py
```

Скрипт читает `bali/content.json` и перезаписывает `bali/index.html`.
Сборка нужна после **любой** правки контента.

## Что где менять

| Что | Где в `content.json` |
| --- | --- |
| Цена, предоплата, состав пакета | `price` |
| Даты, длительность, маршрут в шапке | `config`, `hero` |
| Дни программы | `program.chapters[].days[]` |
| Отели | `stay.cards[]` |
| Ведущие и организатор | `leaders`, `lab`, `organizer` |
| Вопросы и ответы | `faq` |
| Контакты, Telegram, WhatsApp | `config` |
| Title, description, canonical, OG | `meta` |

### Опубликовать цену

В `price` добавить два поля — блок сам переключится с «уточняется» на цифру:

```json
"amount": "1 950 €",
"terms": "Одноместное размещение +450 €. Предоплата 600 € при бронировании."
```

### Подключить форму

`config.formEndpoint` — адрес приёмника заявки (Formspree, Getform, собственный
обработчик). Пока поле пустое, форма работает резервным путём: собирает
заполненное сообщение и открывает Telegram организатора. Проверьте оба
состояния — успех и ошибку — до запуска рекламы.

`config.replyWindow` — срок ответа («в течение суток»). Оставлен пустым
намеренно: по ТЗ срок нельзя публиковать до подтверждения реального процесса.

### Подключить аналитику

`config.analytics.ymCounterId` — номер счётчика Яндекс.Метрики. Сам счётчик
добавляется в `head` отдельно. Цели уже расставлены в `script.js`:
`cta_header`, `cta_hero`, `cta_mobile`, `cta_route`, `form_start`,
`form_success`, `form_error`, `program_day_open`, `faq_open`,
`telegram_click`, `whatsapp_click`, `scroll_25/50/75/100`.

## Фотографии

Реальных балийских кадров пока нет. Вместо стоковых картинок на странице стоят
тональные слоты с описанием нужного кадра — это же и есть ТЗ фотографу.
Портреты Ильи и Андрея временно взяты из архива непальского проекта.

Как подставить настоящее фото:
1. Положить `имя.jpg`, `имя.webp`, `имя-m.jpg`, `имя-m.webp` в `bali/images/`.
2. В `content.json` указать путь без расширения: `"image": "images/имя"`.

Первый экран: чтобы заменить типографическую заставку на фотографию, в
`hero.image` передать `{"src": "images/hero", "srcMobile": "images/hero-m",
"alt": "…", "width": 2400, "height": 1000}`.

- [ ] `meta.ogImage` → обложка 1200 × 630
- [ ] Цена, состав пакета, правила отмены
- [ ] Подтверждённые отели вместо списка требований
- [ ] Портрет и био Виты, фото практик и локаций
