# Соль. Рис. Тишина. — лендинг

Путешествие-практика по Бали и Гили Мено, 12–22 февраля 2027.
Собран по ТЗ «ПРОЕКТ БАЛИ 2027» от 14 сентября 2026.

## Как устроено

```
bali/
  content.json   ← весь текст, даты, цены, контакты, программа. Правится здесь.
  index.html     ← собирается из content.json, руками не правится
  styles.css     ← дизайн-система
  script.js      ← меню, аккордеоны, форма, аналитика
  docs/          ← внутренние материалы (на сайт не попадают)
scripts/
  build_bali.py  ← сборка
```

Страница статическая: ни одного внешнего скрипта, только шрифты Google.
Весь текст программы лежит в HTML и индексируется.

## Сборка

```bash
python3 scripts/build_bali.py
```

Скрипт читает `bali/content.json` и перезаписывает `bali/index.html`.
Сборка нужна после **любой** правки контента.

## Что где менять

| Что | Где в `content.json` |
| --- | --- |
| Цена, предоплата, состав пакета | `price` |
| Даты, длительность, маршрут в шапке | `config`, `hero` |
| Дни программы | `program.chapters[].days[]` |
| Отели | `stay.cards[]` |
| Ведущие и организатор | `leaders`, `lab`, `organizer` |
| Вопросы и ответы | `faq` |
| Перелёт и прибытие | `arrival.rows[]` |
| Контакты, Telegram, WhatsApp | `config` |
| Title, description, canonical, OG | `meta` |

### Опубликовать цену

В `price` добавить два поля — блок сам переключится с «уточняется» на цифру:

```json
"amount": "1 950 €",
"terms": "Одноместное размещение +450 €. Предоплата 600 € при бронировании."
```

### Подключить форму

`config.formEndpoint` — адрес приёмника заявки (Formspree, Getform, собственный
обработчик). Пока поле пустое, форма работает резервным путём: собирает
заполненное сообщение и открывает Telegram организатора. Проверьте оба
состояния — успех и ошибку — до запуска рекламы.

`config.replyWindow` — срок ответа («в течение суток»). Оставлен пустым
намеренно: по ТЗ срок нельзя публиковать до подтверждения реального процесса.

### Подключить аналитику

`config.analytics.ymCounterId` — номер счётчика Яндекс.Метрики. Сам счётчик
добавляется в `head` отдельно. Цели уже расставлены в `script.js`:
`cta_header`, `cta_hero`, `cta_mobile`, `cta_route`, `form_start`,
`form_success`, `form_error`, `program_day_open`, `faq_open`,
`telegram_click`, `whatsapp_click`, `scroll_25/50/75/100`.

## Стиль

Страница свёрстана как печатный глянцевый журнал: обложка с названием во всю
ширину полосы, строками анонса и номером выпуска, золотая бегущая лента,
разворот на всю ширину, главы маршрута
с римскими цифрами.

Графика страницы:

- круглая вращающаяся печать на обложке;
- полоса крупных цифр (11 дней, 4 главы, 5 ночей, 0 машин);
- лента «Бали в кадрах» — сама плывёт, листается стрелками, свайпом,
  тачпадом и мышью; бесконечная по кругу;
- медленный «наезд камеры» на обложке, развороте и фото-разрывах;
- рисованная карта маршрута (`scripts/bali_map.py`, береговые линии Natural Earth
  в `scripts/data/bali-land.json`), путь прорисовывается при прокрутке; на телефоне —
  отдельная кадрированная карта;
- фото-разрывы во всю ширину с крупной строкой (Батур, Гили);
- кадр у каждого дня программы;
- лента фото на тёмном фоне, блок организатора с портретом в рамке.

При `prefers-reduced-motion` анимации выключены, лента становится обычной
горизонтальной прокруткой. Светлая бумага, чернильный текст, золото — акцент.
Цвета — Pantone весна 2027, объявлены в `:root` в `bali/styles.css`:

| Токен | Цвет | Роль |
| --- | --- | --- |
| `--paper` | #f6f2ea | основная бумага |
| `--cream` | #ede7db Antique White | чередующиеся разделы |
| `--ink` | #1f2638 Blue Indigo, до чернил | текст |
| `--night` | #232b3e | тёмные разделы, форма |
| `--gold` | #c3a057 Arrowwood | кнопки, лента, акценты на тёмном |
| `--gold-ink` | #6c5320 | акцентный текст на светлом |
| `--reed` | #575a3e Tarragon | списки практик |
| `--muted` | #5a5d66 Dolphin | второстепенный текст |

Шрифты — строгая пара: Noto Serif Display 400 только для заголовков, имён
и крупных цифр (без курсива и тонких начертаний); весь остальной текст —
Manrope. Контраст всего текста проходит WCAG AA; проверять после
любой правки цветов.

## Заявки в Telegram

Форма шлёт заявку на `config.formEndpoint`. Готовый приёмник, который
пересылает заявку ботом в личку, — `telegram-bot/worker.js`, настройка за
10 минут в `telegram-bot/README.md`. Пока адрес пустой, форма открывает
Telegram с заполненным текстом заявки.

## Перед запуском

- [ ] `meta.noindex` → `false` (сейчас `true`, чтобы черновик не попал в поиск)
- [ ] `meta.siteUrl` → финальный домен, обновить canonical и OG
- [x] `meta.ogImage` → обложка 1200 × 630 (собирается `scripts/og/og-template.html`)
- [ ] Отзывы участников с именами и разрешением — `testimonials.items`
- [ ] Цена, состав пакета, правила отмены

- [ ] Портрет и био Виты, фото практик и локаций

- [ ] Схема `Event` — по ТЗ добавляется только после появления цены
